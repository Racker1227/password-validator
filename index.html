Welcome to Password Validator

Rules

  1. Password characters should be range 8-15 characters
  2. Password must have atleast one number, alphabet (Uppercase and lowercase) and Special character like !@#$%_
  3. Password cannot have consecutive letter and numbers like abc, 123
  4. Password cannot have Month Name or Day name like Monday, Mon or Jan or January
  5. Password cannot have mobile number (10 numbers consucutive)
